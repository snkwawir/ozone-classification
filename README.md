# Ozone Level Classification System

## Overview
This project develops machine learning classification models to predict high-risk ozone conditions using atmospheric and environmental datasets from El Paso, Texas. The analysis compares logistic regression and artificial neural network approaches while emphasizing preprocessing workflows, feature analysis, statistical validation, and predictive model evaluation.

## Objectives
- Predict high-risk ozone conditions using environmental variables
- Compare traditional statistical models against neural network approaches
- Develop preprocessing and validation workflows for atmospheric datasets
- Identify environmental factors most strongly associated with elevated ozone levels
- Evaluate classification performance using ROC/AUC and confusion matrix analysis

## Tools & Technologies
- R
- caret
- glmnet
- neuralnet
- ggplot2
- ROC/AUC Analysis
- Machine Learning
- Statistical Modeling

## Key Features
- Built logistic regression and neural network classification models
- Developed preprocessing, train/test partitioning, and validation workflows
- Performed exploratory analysis and feature correlation assessment
- Applied Elastic Net regularization and hyperparameter tuning techniques
- Evaluated model performance using confusion matrices, ROC curves, and AUC metrics

## Results
The logistic regression model achieved approximately 85.9% classification accuracy and significantly outperformed the neural network model, demonstrating that simpler statistical models can outperform more complex architectures on structured environmental datasets.
